How to Use:
  • Adjust the parameters on the left — results and the plot update automatically.
  • Path Loss Exponent (n): how quickly the signal fades with distance. 2.0 is free space (true FSPL); 1.6–1.8 indoor line-of-sight (corridor waveguiding); 2.7–3.5 urban cellular; 3–5 shadowed urban; 4–6 indoor obstructed.
  • Path Loss Model: the reference distance d0 used by the log-distance model. The 1 km reference is common for outdoor/long-range links; the 1 m reference is often used for indoor/short-range analysis. Both agree exactly at n = 2.
  • Fade margin is kept separate from n: the exponent sets the mean loss trend with distance, while the fade margin covers variation around that mean (log-normal shadowing, typically σ = 4–12 dB, and multipath fading).
Max allowable path loss = Ptx + Gtx + Grx − Ltx − Lrx − fade margin − misc. losses − receiver sensitivity. Distance is then solved from the log-distance model PL(d) = FSPL(d0) + 10·n·log10(d/d0), where FSPL(d0) is free-space loss at the reference distance (n = 2). The exponent scales only the distance ratio beyond d0, never the frequency term.
