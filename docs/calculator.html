How to Use:
  • Adjust the parameters on the left — results and the plot update automatically.
  • FSPL Exponent (n): how quickly the signal fades. 2.0 is ideal free space; higher values represent more obstructed environments (urban, indoors).
  • Path Loss Model: the reference distance used in the path loss equation. The 1 km model is common for outdoor/long-range links; the 1 m model is often used for indoor/short-range analysis.
Max allowable path loss = Ptx + Gtx + Grx − Ltx − Lrx − fade margin − misc. losses − receiver sensitivity. Distance is then solved from the selected path loss model.
